# tronfaucet

Локальный сервис для Tron-кошельков, выведенных из **одной** мнемоники и пасфразы (BIP39/BIP44, путь `m/44'/195'/0'/0/{index}`).
При запуске открывает веб-UI со списком кошельков, их балансами в TRX и USDT, кнопкой «сгенерировать новый» и формой отправки.

Приватные ключи **не хранятся на диске**: в `data/wallets.json` лежат только индексы деривации, адреса и метки. Ключ выводится из мнемоники в момент подписи транзакции.

## Запуск

```bash
# мнемоника сгенерируется в ./data/mnemonic.txt при первом запуске
go run ./cmd/tronfaucet

# или со своей мнемоникой
MNEMONIC="слова ..." PASSPHRASE="" go run ./cmd/tronfaucet
```

UI откроется на http://127.0.0.1:8080 автоматически.

## Конфигурация

Значения берутся из `./config.yaml` (необязателен), затем из переменных окружения — окружение приоритетнее. Шаблон: [config.yaml.example](config.yaml.example).

| Переменная         | По умолчанию     | Что делает                                                 |
| ------------------ | ---------------- | ---------------------------------------------------------- |
| `ADDR`             | `127.0.0.1:8080` | адрес прослушивания                                        |
| `DATA_DIR`         | `./data`         | где лежат `wallets.json` и `mnemonic.txt`                  |
| `OPEN_BROWSER`     | `true`           | открывать браузер при старте                               |
| `MNEMONIC`         | —                | пусто → генерируется и пишется в `{DATA_DIR}/mnemonic.txt` |
| `PASSPHRASE`       | —                | пасфраза BIP39                                             |
| `NETWORK`          | `mainnet`        | `mainnet` или `nile`                                       |
| `NODES`            | —                | пусто → дефолтные ноды сети (см. ниже)                     |
| `TRON_PRO_API_KEY` | —                | ключ TronGrid, снимает лимиты публичных нод                |
| `USDT_CONTRACT`    | —                | пусто → дефолтный контракт сети                            |
| `FEE_LIMIT_TRX`    | `50`             | лимит комиссии для TRC20-переводов                         |

Формат `NODES` — список через запятую, `scheme://host[:port][|tier]`. Схемы: `grpc`, `grpcs` (TLS), `http`, `https`. Тир 0 — основной, выше — резерв, используется только когда все ноды младших тиров недоступны:

```
NODES="grpcs://grpc.trongrid.io:50051,https://api.trongrid.io,https://tron-rpc.publicnode.com|1"
```

Дефолты по сетям:

- **mainnet** — USDT `TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t`, ноды TronGrid (tier 0) и PublicNode (tier 1)
- **nile** — USDT `TXLAQ63Xg1NAzckPwKHvzw7CSEmLMEqcdj`, ноды `grpc.nile.trongrid.io:50051` и `https://nile.trongrid.io`

Символ и число знаков токена читаются из контракта на старте и пишутся в лог — это же и проверка, что контракт задан правильно.

## Безопасность

- **Мнемоника — единственный способ восстановить средства.** Файл `data/mnemonic.txt` создаётся с правами `0600`; забэкапьте его.
- **Пасфразу нельзя менять после создания кошельков** — адреса станут другими. Сервис хранит в `wallets.json` контрольный адрес нулевого индекса и откажется стартовать при несовпадении. Файл без этого адреса тоже отклоняется.
- **API не имеет аутентификации**: кто дотянулся до порта — тот отправляет средства. Держите `ADDR` на `127.0.0.1`, не выставляйте наружу.
- От запросов, которые чужая веб-страница делает через браузер пользователя, стоит защита: проверяются `Sec-Fetch-Site` и `Origin`, а изменяющие запросы обязаны иметь `Content-Type: application/json` — из-за этого браузер вынужден слать preflight, который не проходит. Тело запроса ограничено 64 КБ.
- `data/`, `config.yaml` и `.env` добавлены в `.gitignore`.

## API

| Метод   | Путь                        | Назначение                                                              |
| ------- | --------------------------- | ----------------------------------------------------------------------- |
| `GET`   | `/api/info`                 | сеть, обозреватель, контракт и децималы токена                          |
| `GET`   | `/api/wallets`              | список кошельков                                                        |
| `POST`  | `/api/wallets`              | создать следующий индекс, тело `{"label":"..."}`                        |
| `PATCH` | `/api/wallets/{index}`      | переименовать                                                           |
| `GET`   | `/api/balances`             | балансы всех кошельков; `?refresh=1` минует кеш (TTL 15с)               |
| `POST`  | `/api/wallets/{index}/send` | `{"asset":"trx"\|"usdt","to":"T...","amount":"1.5"}` → `{"txid":"..."}` |

Изменяющие запросы (`POST`, `PATCH`) требуют заголовок `Content-Type: application/json`. Ошибки ввода возвращают `400`, отказ ноды — `502`.
